## 数据保护和授权

旧桌面、文件与身份服务停写后，对 Files shared 目录和身份 PostgreSQL 做完整快照。新主机恢复后，对现有用户（含密码字段）、直接应用授权、角色、角色成员、安全密钥和 TOTP 数据逐项比对，通过后执行追加迁移并再次比对。数据库和认证密钥配套迁移；没有导入本地体验账户或测试数据库。

追加迁移为头像字段、Office One 应用目录、资源管理应用目录。Office One 和资源管理通过既有 `platform-admin` 角色开放；未修改角色成员，未加入普通用户默认应用。新建 `resource-manager` 独立服务客户端；原服务客户端、secret、签名密钥和已有回调地址保留。

旧主机的桌面与身份 Nginx 改为验证 TLS 证书的 HTTPS 转发，用于兼容尚未更新的 DNS 缓存。旧应用容器停止，数据保留作回滚依据，不能与新主机同时恢复写入。
