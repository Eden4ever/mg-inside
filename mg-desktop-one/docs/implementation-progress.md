## 本次形成的架构

公共前端位于 ../mg-platform/packages/frontend，独立个人中心位于 ../mg-personal-one。个人中心使用 JSON 配置和组件注册表；其它应用已共享外壳能力，尚未全部迁入 JSON。

标准应用共用页头、导航、PageFrame、内容卡片及桌面认证桥接。文档是独立阅读范式，保留认证和桌面接入，自主管理文字目录、正文、本页目录与代码样式。

中心访问令牌续期延长同一枚令牌，默认12小时有效、72小时绝对期限。统一登录不替代业务权限。Token One 控制台仅向真实业务管理员展示，中心管理员身份不自动获得控制台权限。

## 已确认交互

- 桌面：企业 Logo 和当前应用菜单，头像直接进入个人中心，铃铛打开通知页。桌面设置在个人中心，不再有 Dock 设置按钮。
- 图标：六应用独立扁平图片，桌面/网格/Dock 使用同一组件和映射。图片资源未做体积优化，目前合计约5MB。
- 窗口：左侧半屏按钮；右侧依次外部打开、最小化、最大化/还原、关闭，统一Windows式尺寸。摆放操作不锁定拖动，拖动保留当前尺寸。
- 普通浮窗可进入 Dock 区域和部分移出视口，但保留可抓取标题区域；最大化与半屏初始摆放贴住 Dock，保留圆角与外阴影。
- 桌面嵌入使用父窗口统一毛玻璃，应用壳与侧栏透明，正文保留底色；独立浏览器保留应用原样式。
- 关闭无编辑且无任务的窗口为纯本地操作。未保存/忙态使用桌面本地确认，可继续使用、交应用处理或明确直接关闭；保存失败保留内容。
- 离线 Dock 偏好先保存本机，恢复网络再同步，后台读取不会覆盖未同步改动。首次加载应用资源、登录、业务保存和会话撤销仍需要网络。
- 通知按账号持久化，支持已读/清除；后台刷新不能吞掉用户点击。
- 页面正文滚动条进入原有右侧留白，与固定标题/操作按钮对齐，覆盖标准 PageFrame 和既有一级业务滚动布局。
