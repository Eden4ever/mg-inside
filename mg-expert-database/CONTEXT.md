# 营商环境指标知识库领域上下文

## 指标体系职责

- **体系职责**：用户在一个指标体系中的实际能力集合，包括查看、研究、目录维护、审核和发布。
- **默认职责**：用户账号上的默认分类，用于用户管理、候选人筛选和工作习惯提示；不限制体系职责。
- **体系授权**：针对 `(指标体系, 用户)` 保存的能力集合。一个用户可以在不同体系拥有不同能力组合。
- **研究分派**：针对 `(指标体系版本, 三级指标, 用户)` 的具体研究范围授权；只有拥有体系研究能力且被分派到该三级指标的用户才能编辑研究内容。
- **系统管理员**：平台级超级管理员，默认拥有所有体系能力，但其操作仍必须经过统一审计。

## 权限不变量

1. 拥有任一体系能力（除查看外）时必须同时拥有该体系查看能力。
2. 体系职责不由用户的默认职责裁剪；默认职责不是授权来源。
3. 研究、依据和 AI 建议采纳需要体系研究能力；三级指标研究员还必须满足研究分派。
4. 目录维护、体系审核和版本发布分别由对应体系能力控制，不能用其他体系的授权替代。
5. 撤销查看能力会同时撤销该体系的其他能力，但不会影响用户在其他体系中的授权。
