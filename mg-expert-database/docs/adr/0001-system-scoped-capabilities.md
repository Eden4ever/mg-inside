# ADR-0001：平台角色与体系权限分离，体系能力采用体系级授权

## 状态

已接受

## 背景

系统需要支持同一用户在不同指标体系承担不同分工，例如在体系 A 研究、体系 B 审核、体系 C 发布。旧实现把全局用户角色作为体系权限的能力上限，导致体系授权无法表达真实组织分工。

## 决策

- `User.role` 保留为平台角色，仅用于账号分类，不作为体系能力上限。
- `IndicatorSystemAccess` 是非系统管理员在具体指标体系中的唯一能力来源。
- `canView` 是 `canResearch`、`canManageCatalog`、`canReview`、`canPublish` 的前置条件；保存任一后者时自动补齐查看权限。
- 系统管理员绕过体系 ACL 读取完整能力，但所有写操作继续保留服务端审计。
- 三级指标研究分派继续独立存在；研究员必须同时满足体系 `canResearch` 和该三级指标分派。

## 影响

- 后端权限守卫与业务服务必须统一依赖体系能力，不能重复按全局角色裁剪。
- 前端体系授权表必须允许任意非管理员用户编辑五类体系能力。
- 研究员候选列表需要按体系研究授权生成，不能只按 `role === researcher`。
- 旧的“全局角色决定能力上限”测试和说明必须改为体系级授权语义。
