# 改密码安全边界验证

2026-09-07。结果：fixed，范围仅为改密码入口的竞态、失败限流和 MFA 复核，不代表全项目安全验收或生产发布完成。

## 修复

`apps/api/src/auth.ts` 的 `changePassword` 原先在事务外验证密码，事务内无条件覆盖哈希。现以 User 行锁覆盖会话重新检查、旧密码验证、哈希及更新；同账户并发请求使用 NOWAIT 拒绝排队。会话必须属于当前用户、未撤销、未过期且安全版本一致。密码失败计入既有十五分钟五次共享预算，提交计数后返回错误。

开启 MFA 后，改密要求服务器记录的第二因子仍在当前允许列表（或恢复验证），且验证时间处于最近五分钟；过期、未来时间及仅密码会话均拒绝。成功仍保留当前会话、撤销其他会话、写审计。页面原接口不变，403/429 提示保留用户输入。
