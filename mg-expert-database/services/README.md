# 指标体系查询服务

`expert-database.api 1.1.0` 已于 2026-09-09 正式登记启用，覆盖体系列表、体系详情和语义库列表。`manifest.json` 为操作索引，`openapi.json` 为完整 OpenAPI 3.1.1 契约，`registration.json` 为登记包。更新时增加版本，并同步公共目录；已发布契约不可覆盖。

知识库使用体系共享授权：普通用户只能查看获准访问的体系及其语义库，系统管理员可查看全部。服务登记与应用入口权限不替代体系授权。列表无授权返回空集合；详情无权限返回 403，管理员查询不存在体系返回 404。返回提供方原始 JSON，不额外增加 data 包装。

体系列表取最新年份的版本；没有版本时相关字段为 null。详情返回体系资料和有序版本列表，不包含研究正文或指标树。语义库返回最近构建摘要和当前生效构建 ID，两者可能不同；configured 仅说明配置状态。三项只读查询不调用向量模型，不构建索引，不产生推理费用。

契约生成工具：桌面项目 `scripts/write-expert-contract.py`；同步工具 `scripts/sync-provider-contracts.mjs`。验收使用 `apps/api/test/service-contract.integration.spec.ts`：独立本地 PostgreSQL Schema、真实登录及 HTTP 请求，覆盖管理员、两个普通账户、授权撤销、空版本、未构建和排队构建，以及 401/403/404 响应。测试结束移除专用 Schema。

发布：桌面核心 `20260908T190350Z`，知识库前端最终 `20260908T190645Z`。正式体系与语义库统一出口调用成功，持久化契约摘要与源码一致，页面标题、列表和新建放弃确认已核验。生产 API 及业务数据库未因本批契约/前端发布迁移。
