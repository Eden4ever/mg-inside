# Office One

已部署在统一桌面 `/apps/office-one/`，与文件服务及 ONLYOFFICE Docs 配合，提供文档、表格和演示文稿编辑。2026-09-09 已接入公共服务出口。

本次前端发布 `20260908T184200Z`，桌面核心 `20260908T184100Z`。`office-one.api 1.1.0` 的六操作 OpenAPI 契约已登记启用，生产摘要与源码一致。未保存确认采用公共弹窗，多个离开入口合并确认，保存或创建期间阻止离开；创建成功后正常进入编辑器，重试也经过离开保护。浏览器标题使用公共应用标题函数。

“我的文档”支持“全部文档”和“最近打开”：前者按修改时间排列，后者按当前账户成功创建打开会话的时间倒序排列。历史由服务器持久保存，列表只返回当前用户的文件，回收站文件不会出现。打开记录不改变文件内容版本或修改时间；部署前没有独立打开时间的文件不会被虚构成历史记录。

保存状态仍等待编辑器同步与文件服务落盘回调，不把编辑器收到输入视作已保存。写请求在读取完整响应前保持忙碌状态，离开、切页和关闭保留未保存保护。

验证包含两账户隔离、打开时间排序、回收站排除、持久化、内容版本不变、保存回调及未保存状态；正式环境已验证测试文档预览和最近打开记录。发布详情见 `../mg-desktop-one/deploy/services-release-20260909.md`。
