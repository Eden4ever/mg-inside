# 文档编辑服务契约

`office-one.api 1.1.0` 已正式登记并启用，共 6 个操作：配置状态、文档查询、新建、打开、会话状态和手动保存。`manifest.json` 为操作索引，`openapi.json` 为 OpenAPI 3.1.1 契约，`registration.json` 为登记包。

能力归属 Office One，实际由 Files 后端 `/api/office` 提供；统一出口保持 `office-one` 应用授权和文件所有者检查。文档中的地址仅描述固定提供方挂载，不能改变代理目标。编辑器下载和签名回调不作为公共服务登记。

最近打开按当前账户过滤，成功打开时记录时间，不改变内容版本或修改时间。保存接口返回 queued 仅表示编辑引擎接收请求；会话状态中出现本次 requestId 才证明签名回调已落盘。unchanged 不能冒充本次落盘确认。

修改后须增加版本，同步清单、登记包和公共目录，登记并审阅后启用。已发布版本内容不可覆盖。桌面项目 `apps/server/src/office-contract.test.ts` 使用真实 HTTP 提供方验证六个操作、双账户隔离、回调签名及保存落盘；编辑引擎在测试中使用受控替身。
