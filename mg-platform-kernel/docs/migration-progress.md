# Java 平台内核迁移进度

更新：2026-09-09。目标保持平台后端完整替代，不以部分接口通过或 Java 可以启动认定迁移完成。

## 范围与项目归属

- `mg-platform-kernel`：本轮新建的独立 Java 平台后端。
- `mg-desktop-one`：保留桌面前端、旧 Node 对照实现及跨语言兼容验证。
- `mg-platform`：保留公共前端、应用展示配置和既有服务契约。
- 身份、文件、资源、Office、Token、知识库等独立后端保持原有语言与数据。
- 前端壳化是后续工作；本阶段保持现有交互，完成真实兼容验证后才切换。
