# “文件”应用规划

状态：首版已于 2026-09-08 发布到 `https://desktop.meta-gravity.com/apps/files/`。已实现个人文件、固定桌面、回收站、Finder 双视图与注册弹窗；本文仍保留后续阶段规划，具体已交付范围见 `mg-files-one/README.md`。

## 定位与注册

- 应用唯一 ID：`files`；显示名称：文件；分类：`default`。
- 所有登录用户可以打开应用；文件和文件夹的资源权限单独校验。
- 建议目录：`mg-files-one`；正式入口：`/apps/files/`。
- 桌面环境使用平台窗口、独立浏览器使用公共页头。复用统一认证、主题、通知和注册弹窗。

## 界面

左侧为最近使用、我的文件、收藏、共享文件、回收站。主区域提供面包屑、搜索、列表/图标视图、名称/修改时间/类型/大小排序、多选与右键菜单。工具栏显示新建、上传、移动、下载等当前可用操作。

文件夹双击进入，文件双击预览。第一阶段支持图片、文本、PDF；其他格式先提供下载，不承诺直接编辑 Office 文件。上传显示进度、失败原因和重试，耗时操作不冻结整个窗口。

编辑名称、选择目标文件夹、预览等采用注册弹窗：桌面内可拖出父窗口；浏览器内呈现对话框。敏感确认保留明确的操作名称及目标。

## 文件操作与权限

第一阶段：新建文件夹、上传/下载、重命名、移动、复制、收藏、删除到回收站、恢复与彻底删除。删除优先可恢复，彻底删除单独确认。

个人空间默认仅本人可见。共享空间采用成员/角色资源权限：浏览、下载、上传、修改、删除、分享分别可表达；默认应用资格不等于资源权限。业务附件仍以业务系统授权为准，不能通过文件 ID、预览地址或复制操作绕过原权限。

以不可变 `fileId`、`folderId`、`spaceId` 关联资源；名称仅显示，重命名不改变链接或授权。目录移动禁止循环与越界；同名冲突提供保留两份/替换/取消；覆盖产生版本或明确确认。

本机磁盘通过选择文件、拖入文件或用户授权目录导入，不默认扫描磁盘。浏览器应用不自动拥有 Windows Explorer 的磁盘访问权限。

## 技术结构

前端负责展示和交互；文件服务负责元数据、目录树、权限、配额、回收站及上传任务；对象存储保存文件内容。存储适配器隔离本地开发存储与正式对象存储，业务不拼磁盘路径。

主要实体：Space、Folder、File、FileVersion、ResourceGrant、UploadSession、Favorite、RecycleEntry、AuditEvent。文件元数据包含 ownerId、spaceId、parentId、name、mimeType、size、storageKey、version、createdAt、updatedAt、deletedAt。

核心接口按资源 ID 设计：

- `GET /api/files/entries?parentId=...`：游标分页、排序、筛选。
- `POST /api/files/folders`：新建文件夹。
- `POST /api/files/uploads`、完成上传接口：创建上传任务和完成校验；逐步扩展分片与断点续传。
- `PATCH /api/files/:id`、移动/复制接口：校验资源版本，避免并发覆盖。
- 预览/下载接口：实时鉴权，短期下载地址不替代权限系统。
- 回收站列表、恢复、彻底删除接口：独立校验所有权和操作能力。

下载、预览、搜索结果、批量操作都必须逐项检查资源权限。显示名称、文件扩展名与实际内容类型分开处理；不在桌面同源直接执行用户上传的 HTML/脚本。预览使用受限渲染方式。

## 业务复用接口

平台提供文件选择器和上传组件：`files.pick({multiple,accept,spaceId})`、`files.upload(...)`、`files.preview(fileId)`；返回文件 ID 和受控元数据，不返回永久裸存储地址。浏览器与桌面共用调用方式。

先接入一项真实业务附件流程，再推广到知识库依据材料及其他应用。旧附件通过适配器逐步接入，不一次迁走已有数据，也不重置业务授权。

## 分期与验收

1. 个人空间：目录、基础文件操作、列表/图标视图、预览、回收站、配额提示。验收跨用户不可见、刷新深链接、失败重试及撤销删除。
2. 共享空间：成员与角色资源权限、共享入口、操作记录。验收撤权立即生效、搜索与下载不泄漏、移动复制不扩大权限。
3. 平台文件能力：文件选择器、上传组件、首个业务附件接入、版本与大文件续传。验收业务权限保留、取消不破坏原文件、跨应用引用稳定。

实施前从当前环境确定对象存储适配与配额；开发环境可以使用隔离存储。正式部署容量和生命周期由配置确定，不写死在业务组件。
