# 公共应用壳严格范式

标准应用接入 `ConfiguredApplicationShell`，通过经过 `loadApplicationConfig` 校验的 JSON 提供应用 ID、名称、页面路径／标题、导航模式和 Lucide 图标名。仅开放业务正文、账号操作和页头操作区域；不开放导航结构、顶部“功能导航”标题、自定义折叠按钮及侧栏样式插槽。

导航固定为 flat（一层）、tree（两层）、grouped（分组）三种模式。统一导航宽度、行高、图标尺寸、选中与悬停状态；折叠按钮始终位于底部，折叠时只显示图标，不显示“功能导航”等装饰标题。侧栏默认 64px，展开 256px；窄屏保留图标轨道，展开以覆盖层显示，支持底部按钮、Esc 和遮罩收起，选择页面后自动收起。应用通过主题语义变量提供深浅配色，不直接覆盖公共壳选择器。

`reading` 为文档内容模式，平台提供页头，应用自己的文档目录放在业务内容区域，不伪装成标准侧栏。

导航图标只接受平台 `icons/lucide.json` 中的名称。应用侧传入图标组件注册表不能扩展白名单；配置中的 SVG／HTML／CSS／脚本均无效。应用图标及自定义图片覆盖见公共应用目录和图标资产说明，桌面、Dock 和目录通过唯一应用 ID 读取同一份配置。

已迁移：个人中心、文件、应用管理、Token One 门户和控制台、指标知识库、统一身份认证。知识库和身份认证的管理入口继续由业务角色过滤，路由和服务端访问保护保持；知识库未保存编辑的导航守卫继续生效。文档应用使用 reading 的页头范式及其自有文档目录。业务正文中的表格、表单、编辑器、权限判断不属于公共导航范式。

范式的约束是组件 API、配置 Schema、运行时校验和接入检查；普通 CSS 并非浏览器沙箱，不能声称它能阻止恶意业务代码修改页面样式。后续开发者中心可检查是否绕过标准壳或覆盖保留选择器。

验证：公共配置包含应用自行传入 icons 注册表仍无法扩展平台白名单的回归；真实 Chrome 检查知识库及身份认证在浏览器与嵌入样式下的 64/256px、56px 页头与 42px 桌面标题空间、16px 左上圆角、外阴影及窄屏遮罩。浏览器验证使用本地生产构建和模拟业务 API，不修改真实账号或业务数据。
