# Token One 领域词汇

## 模型

Token One 对外暴露的能力标识。客户端请求使用模型名；模型可以对应多个实际调用来源。

## 模型所有者

定义模型能力、版本和官方命名的主体，例如 OpenAI、Anthropic、DeepSeek。模型通常有一个主模型所有者，但同一能力可能存在别名、兼容实现或第三方托管版本。

## 供应商

向 Token One 提供模型调用能力、价格或额度的主体。供应商可以是模型所有者的官方服务，也可以是第三方中转或聚合平台，例如 CCTQ。

CCTQ 是一个第三方供应商，可以同时供应 OpenAI、Anthropic、DeepSeek 等多个模型所有者的模型；它不从属于其中任何一个模型所有者。

## 供应商账户

Token One 在某个供应商处使用的账户或凭据范围。它承载余额、套餐、用量、过期时间和可见模型等账户状态；它不是一个客户端调用令牌。

## 渠道

Token One 实际发起模型请求时使用的端点、协议、密钥、代理和健康状态集合。一个供应商账户可以对应多个渠道，一个模型也可以通过多个供应商渠道提供。

## 模型路由

把一个对外模型映射到一个供应商渠道及其上游模型名的可执行关系。模型路由可以配置优先级、权重、协议能力和启用状态，并由渠道池选择实际调用目标。

模型与供应商通过模型路由形成多对多关系。模型所有者与模型通常是一对多关系。

## 账户快照

供应商账户在某个采集时刻的只读状态记录，包括原始额度、已用额度、模型/分组目录和同步状态。快照不改变请求路由，除非管理员显式配置余额保护策略。
